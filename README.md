A single-line roast of a smart fridge, written by a deterministic Python program to `entry.txt`. The line targets the 3 a.m. firmware update that locks the fridge behind a new terms-of-service agreement — 140 characters, no setup, just the punchline.

The entry line:

> My smart fridge updated its firmware at 3 a.m. and now it won't open until I accept the new terms — my leftovers are held hostage by a EULA.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/fridge-roast-out python3 main.py
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) with mode 0644.
